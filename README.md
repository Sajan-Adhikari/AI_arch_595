This repo contain method to invoke the ll(or make an api call). There are two ways:
1) by inferance model provider--
In this case, you take an api key from the inference model providers and save the key in your env and save a script in file and run it. Here, we should not hardcode the api key in the script.I've attached the script for your reference.
2) by running locally--
There other methods is running locally. This depends on the computer power of the computer. In my case, I used ollma 3.2b to invoke the model. I have attached commands in the part B of this section.
